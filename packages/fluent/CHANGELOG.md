# @syncrona/fluent

## 1.0.0

### Minor Changes

- Initial release. This is the optional Fluent tier behind `syncrona fluent`. It contains:
  - a lazy, injectable bridge to the ServiceNow SDK orchestrator
  - a credential resolver that turns a stored Basic or OAuth profile into the SDK's auth shape
  - a UI session login for the session-only endpoints that install and transform rely on
