- Add a read-only decoder for legacy Workflows (`wf_workflow`) in `packages/core/src/flow/`, the Workflow counterpart of the flow and playbook documents. `readWorkflowRows` reads a workflow and its published version (the newest one when several are published, with the others named in `warnings`), the version's `wf_stage`, `wf_activity`, `wf_condition` and `wf_transition` rows, and the activities' `glide_var` values from `sys_variable_value`; runtime tables (`wf_context`, `wf_executing`, `wf_history`, logs) are never read. `assembleWorkflowDocument` builds one deterministic `syncrona.workflow/1` document: conditions nested under their activity, the `activity_stages` and `input` payloads decoded, audit columns dropped, secret-typed variable values and secret-typed values inside decoded payloads (gzip ones included) withheld as `<redacted:type>`, and dangling start activities, transition ends and conditions reported in `warnings`. `writeWorkflowDocuments` / `syncWorkflowDocuments` write every workflow of a scope as `<source>/wf_workflow/<name>.workflow.json` with the same file-naming (shared `documentFileNames`), atomic-write, per-document failure and stale-file rules as playbook documents, and `isWorkflowDocumentPath` recognises the files. No command calls it yet; a `workflow` table preset will.
