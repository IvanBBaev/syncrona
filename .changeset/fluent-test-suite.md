- The native Fluent compiler supports `TestSuite()` (`sys_atf_test_suite` and `sys_atf_test_suite_test`), byte for byte as SDK 4.13.6 writes it: memberships coalesced on suite and test, orders derived from position unless pinned, tests and parents given as a sys_id or a record, and the SDK's hints and errors for tied orders, a filter beside explicit tests, duplicate tests and a self-parent.
