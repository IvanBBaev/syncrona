The native Fluent compiler builds `NowAssistSkillConfig()` byte for byte as SDK 4.13 does for skills whose prompts run on an LLM provider: the skill capability with its config and status, the provider definitions, the prompt configs, the input and output attributes, the feature, strategy and resource mappings and the execute ACL with its role restrictions, with the SDK's name, provider, prompt, state and attribute checks. Tools, skill and deployment settings, role-based user access and record/JSON attributes are reported as not supported yet.
